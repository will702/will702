## Selected work

### [mlx-vision](https://github.com/will702/mlx-vision)

DSpark-style speculative decoding for OCR vision-language models on Apple Silicon. The project targets faster local inference for DeepSeek-OCR-2, GLM-OCR, and Unlimited-OCR using MLX.

`Python` `MLX` `Vision-Language Models` `Speculative Decoding`

### [StockPro](https://ipo-tracker.site/)

A production research terminal for the Indonesian stock market: technical and fundamental analysis, broker-flow research, portfolio tooling, paper trading, automated ETL, and AI-assisted workflows.

[Live product](https://ipo-tracker.site/) · [Google Play](https://play.google.com/store/apps/details?id=com.will702.stockpro)

`Next.js` `TypeScript` `PostgreSQL` `Quantitative Finance`

### [QuakeSense](https://github.com/will702/Quakesense.swiftpm)

An earthquake-survival simulation for iOS that turns safety guidance into a two-minute interactive drill using physics, motion controls, procedural audio, haptics, and accessible feedback.

`SwiftUI` `SpriteKit` `Core Haptics` `Core Motion`
